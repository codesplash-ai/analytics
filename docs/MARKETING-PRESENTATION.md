# CodeSplash Analytics marketing presentation

The shared direction applies to all marketing: social posts, blog articles,
newsletters, tutorial/product videos, ads, website copy, store listings and
release updates. Product videos are central. Preserve CodeSplash Ocean & Heat
and this product's established UI and native platform conventions.

CodeSplash AI Brain owns the [Apple research](https://github.com/codesplash-ai/codesplash-brain/blob/master/docs/APPLE-MARKETING-RESEARCH.md)
and [implementation/acceptance plan](https://github.com/codesplash-ai/codesplash-brain/blob/master/docs/MARKETING-PRESENTATION-PLAN.md).
Policy: `codesplash-marketing-presentation-v1`, introduced in catalog revision 16, source `f345425`.
CodeSplash Analytics joined the catalog as `product:analytics` in revision 53.
This file is a pointer and product brief, not a second policy authority.

- **Audience:** Analysts, statisticians, data scientists and ML engineers.
- **Task:** Turn a raw dataset into a tested, explained result.
- **Proof:** A populated dataset, a finding with its reason, and a result with its Python and R code.

Use actual application components with realistic isolated example data. Show
an action and its useful result. Blank, account-blocked or loading screens
cannot substitute for a feature demonstration. Never send sample communications
to real recipients. Web/desktop masters are native 4K; mobile uses accepted
native device dimensions. New captures use Ocean & Heat Dark and videos use
the approved French Fuse soundtrack, branded benefit headers and purposeful
transitions. Preserve evidence and review the complete edit before publication.

Connect deployment facts to the existing Brain → Marketing delivery path.
Match each claim, image/video, destination and available platform. Do not imply
that a web deployment shipped a pending mobile/extension binary. Keep store
review holds explicit. No repository polling or paid spend is added here.

## This repository

This is the public distribution repository: releases and issues. The source
is privately maintained, and its own copy of this file holds the full brief.

- **Releases.** Each GitHub release here is published by the private
  repository's release pipeline. Its notes are written first and published on
  [codesplash.ai/updates](https://codesplash.ai/updates) before the release goes
  public, and the release body is those notes followed by the download and
  `SHA256SUMS` footer. The same notes appear on the
  [changelog](https://analytics.codesplash.ai/changelog).
- **Media.** Screenshots and walkthrough videos are captured from the
  published, signed release for macOS 14 or later on Apple Silicon, using its
  sample data and the Ocean & Heat Dark theme. There are no Windows or Linux
  builds, so no media shows one.
- **Claims.** Copy here, in release notes and in marketing follows the same
  claims rules as [analytics.codesplash.ai](https://analytics.codesplash.ai),
  and its numbers come from the site's published proof.

Status: policy and brief established, and the product is live and public since
v0.9.0. v0.9.3 is the first marketed release. Capture, visual acceptance and
publication remain tracked in the shared roadmap. This document does not claim
a new release or completed media delivery.
